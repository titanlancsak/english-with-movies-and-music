their own licenses:

FFmpeg (tools\ffmpeg.exe, tools\ffprobe.exe and their DLLs)

  Build:   https://github.com/BtbN/FFmpeg-Builds
  Source:  https://ffmpeg.org/download.html and https://github.com/FFmpeg/FFmpeg

whisper.cpp (tools\whisper\)
  License: MIT
  Source:  https://github.com/ggml-org/whisper.cpp

yt-dlp (tools\yt-dlp.exe)
  License: The Unlicense (public domain)
  Source:  https://github.com/yt-dlp/yt-dlp

eSpeak NG (tools\espeak-ng\)
  License: GNU General Public License v3
  Source:  https://github.com/espeak-ng/espeak-ng

Phoneme recognizer (tools\phonemes\), built with PyInstaller from
Sources/EnglishWithMovies/Phonemes/worker.py. It contains:
  Python (PSF License) — https://www.python.org
  ONNX Runtime (MIT) — https://github.com/microsoft/onnxruntime
  NumPy (BSD 3-Clause) — https://numpy.org
  Its model is downloaded when the user turns on the sound analysis:
  facebook/wav2vec2-lv-60-espeak-cv-ft (Apache 2.0), converted to int8 ONNX —
  https://huggingface.co/facebook/wav2vec2-lv-60-espeak-cv-ft

Whisper speech recognition models (ggml format; tools\models\ggml-base.en.bin
is included, larger models are downloaded by the app when chosen)
  License: MIT (OpenAI Whisper)
  Source:  https://huggingface.co/ggerganov/whisper.cpp

Online services used by the app:
  Wiktionary (definitions and examples), CC BY-SA 4.0 — https://en.wiktionary.org
  Free Dictionary API — https://dictionaryapi.dev
  MyMemory translation API — https://mymemory.translated.net

Flutter packages are listed in the source code (app-flutter/pubspec.yaml),
each under its own open-source license.
